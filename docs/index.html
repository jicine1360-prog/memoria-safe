Memoria 안전 — 개인정보처리방침

최종 갱신: 2026-10-05

Memoria 안전(이하 "앱")은 사용자가 직접 발동한 SOS와, 사용자가 켠 패턴 감지 시 사용자가 지정한 보호자에게 위치·알림·증거를 전송하는 개인 안전 앱입니다. 응급기관에 자동으로 신고하지 않으며, 응급 서비스를 대체하지 않습니다.

1. 수집·전송하는 정보

구분내용목적
위치(좌표)SOS·분실 모드 중 위치, 최근 경로(KML)보호자에게 위치 안내
음성감지 시점 전후 약 10초사고 증거
화면 캡처사용자가 허용한 경우에 한함사고 증거
기기 식별자앱 내부에서 생성한 ID기기 구분

이 정보는 사용자가 지정한 Telegram 봇·챗으로만 전송됩니다. 이메일 전송은 현재 보류(비활성) 상태입니다.

2. 수신자 및 국외 이전

  • 수신자는 사용자가 설정 화면에서 직접 입력한 Telegram 봇·챗 ID로 한정됩니다.
  • Telegram은 해외에 서버를 두므로 위치·증거가 해외에서 처리될 수 있습니다.
  • 광고·판매·프로파일링 목적의 공유는 하지 않습니다.

3. 동의와 통제

  • 최초 실행 시 동의 화면을 거쳐야 사용할 수 있습니다.
  • 감지·녹음·위치 공유가 실행 중이면 Android 포그라운드 알림으로 항상 표시됩니다.
  • 설정에서 언제든 감지·공유를 끌 수 있습니다.
  • 보호자는 Telegram 봇에 /lost(분실 모드 켜기), /stop(중지)을 보내 원격으로 제어할 수 있습니다. 이 명령은 기기가 Telegram에서 직접 조회합니다.

4. 보존·삭제

  • 기기에 저장된 증거 파일(음성·경로·화면 캡처)은 생성 후 7일이 지나면 앱 시작 시 자동 삭제됩니다.
  • 전송에 성공한 임시 사본은 삭제됩니다.
  • 사용자는 앱 데이터 삭제 또는 앱 제거로 로컬 데이터를 지울 수 있습니다.
  • 삭제 요청은 아래 연락처로 할 수 있습니다.

5. 보안

전송 구간은 HTTPS/TLS(Telegram Bot API)를 사용합니다. 증거 파일은 앱 전용 저장소에 저장되며 자체 암호화는 하지 않습니다. 봇 토큰 등 자격증명은 Android Keystore로 암호화합니다.

6. 아동

이 앱은 만 13세 이상을 대상으로 하며, 아동으로부터 고의로 정보를 수집하지 않습니다.
