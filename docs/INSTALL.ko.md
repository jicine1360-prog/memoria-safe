# Memoria 안전 설치 안내 (Android)

## 1. 준비물

- Android 8.0(API 26) 이상 스마트폰
- 인터넷 연결 (Wi-Fi 또는 데이터)
- 수신자 알림용 **Telegram** 앱 (보호자·가족도 설치)

## 2. 설치 (APK 직접 설치)

1. 배포받은 `app-release.apk` 파일을 폰으로 옮깁니다(USB, 클라우드, 메신저 등).
2. 파일 관리자에서 APK 파일을 탭합니다.
3. **출처를 알 수 없는 앱 설치** 허용을 요청하면 허용합니다.
   - 설정 → 앱 → 특수 접근 → **알 수 없는 앱 설치** → 사용하는 파일 관리자/브라우저 허용
4. **설치**를 누르고 완료될 때까지 기다립니다.
5. 홈 화면의 **Memoria 안전** 아이콘을 눌러 실행합니다.

> Play 스토어 버전이 배포되면 Play 스토어에서 검색해 설치하면 됩니다(현재 미등록).

## 3. 첫 실행과 권한

1. **이용 동의** 화면에서 수집 정보·전송 대상·보존 내용을 확인하고
   **모두 동의하고 시작**을 누릅니다. 동의하지 않으면 앱이 종료됩니다.
2. 권한 요청이 뜨면 항목별로 허용합니다.
   - **위치**: 긴급 시 위치 전송
   - **마이크**: 감지 시점 주변 음성(증거)
   - **카메라**: 화면 캡처(선택, 설정에서 켤 때만)
   - **알림**: 실행 중 표시 및 비상 알림
3. 분실 모드에서 백그라운드 위치가 필요하면 **위치 → 항상 허용**으로 설정합니다.

## 4. Telegram 봇 만들기 (보내는 쪽)

1. Telegram에서 **@BotFather** 를 엽니다.
2. `/newbot` 을 보냅니다.
3. 봇 **이름**과 **사용자명**(`...bot` 으로 끝나야 함)을 입력합니다.
4. 발급된 **봇 토큰**을 복사합니다. 예: `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxx`

## 5. 수신자 챗 ID 확인

1. 만든 봇과의 대화를 열고 **아무 메시지나 한 번** 보냅니다.
2. 브라우저에서 아래 주소를 엽니다(토큰 부분을 실제 값으로 교체).
   ```
   https://api.telegram.org/bot<봇토큰>/getUpdates
   ```
3. 응답에서 `"chat":{"id": 123456789 }` 의 **숫자**가 챗 ID입니다.
4. 가족이 여러 명이면 각자 봇에 메시지를 보낸 뒤, 각자의 챗 ID를 모읍니다.

> 개인정보 보호를 위해 봇 토큰과 챗 ID는 채팅·게시물에 공개하지 마세요.

## 6. 앱에 수신자 설정

1. 앱 오른쪽 아래 **설정(⚙)** 을 엽니다.
2. **Telegram** 항목에 **봇 토큰**과 **수신자 챗 ID**(여러 명은 쉼표로 구분)를 입력합니다.
   예: `111111111, 222222222`
3. **테스트**를 눌러 수신자에게 테스트 메시지가 도착하는지 확인합니다.

## 7. 동작 확인

- **위험신호(SOS)**: 메인 화면의 빨간 SOS 버튼을 약 **3초 길게** 누릅니다.
  수신자에게 알림·위치가 도착하고, 증거(약 10초 음성, 설정 시 화면 캡처)가 전송됩니다.
- **분실신호**: 보호자가 봇에 `/lost` 를 보내면 위치 공유가 시작되고, `/stop` 으로
  중지됩니다.

## 8. 소스에서 직접 빌드 (개발자)

요구 환경: Android SDK 36, JDK 17 이상, Gradle 8.13(포함된 launcher 사용)

```bash
cd android
./gradlew test
./gradlew assembleDebug            # 디버그 APK
./gradlew bundleRelease            # Play 제출용 AAB (로컬 서명 필요)
```

Release 서명은 저장소에 포함되지 않습니다. `android/keystore.properties` 를 로컬에서
만들어 사용하고, 키스토어·암호는 절대 커밋하지 마세요.

## 9. 문제 해결

| 증상 | 확인할 것 |
|---|---|
| 알림이 안 옴 | 봇 토큰·챗 ID 오타, 수신자가 봇에 `/start` 했는지, 인터넷 연결 |
| 위치가 안 옴 | 위치 권한(항상 허용), GPS 켜짐 여부 |
| 마이크 증거 없음 | 마이크 권한, 설정에서 증거 수집 켜짐 여부 |
| 분실 모드 안 됨 | 보호자 챗 ID가 수신자 목록에 있는지, `/lost` 철자 |
| 설치 차단됨 | 알 수 없는 앱 설치 허용, 파일 손상 여부 |

## 10. 주의

- Memoria는 응급구조기관을 대체하지 않습니다. 실제 위험 시 현지 긴급번호
  (**한국 119·112**, 미국 911 등)에 직접 신고하세요.
- 실행 중에는 Android의 마이크·위치 표시가 유지되며, 앱이 이를 끄거나 숨기지 않습니다.
