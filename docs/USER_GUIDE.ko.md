# Memoria 안전 사용자 안내 (Android)

Memoria 안전은 **기기 소유자가 동의하고 직접 설정한 개인 안전 앱**입니다.
응급기관에 자동으로 신고하지 않으며, 긴급 시에는 현지 긴급번호에 직접 연락하세요.
(한국 119·112, 미국 911 등)

## 1. 설치와 첫 실행

1. 설치한 APK로 앱을 엽니다.
2. 첫 화면의 이용 동의 내용(수집 정보·전송 대상·보존)을 확인하고
   **모두 동의하고 시작**을 누릅니다. 동의하지 않으면 앱이 종료됩니다.
3. 카메라·마이크·위치·알림 권한을 허용합니다. 감지·수집은 사용자가 켠 경우에만
   동작하며, 실행 중에는 Android 알림으로 항상 표시됩니다.

## 2. Telegram 수신자 설정

1. 오른쪽 아래 **설정(⚙)** 을 엽니다.
2. **Telegram** 항목에 발급받은 **봇 토큰**과 **수신자 챗 ID**(여러 명은 쉼표로
   구분)를 입력합니다.
3. **테스트**를 눌러 수신자에게 테스트 메시지가 도착하는지 확인합니다.
   (이메일 전송은 현재 보류 상태입니다.)

## 3. 위험신호 (SOS)

- 메인 화면 가운데의 빨간 **SOS 버튼**을 약 **3초 길게** 누르면 발동됩니다.
- 발동하면 지정한 수신자에게 **알림과 위치**가 전송되고, 감지 시점 전후 **약 10초
  음성**(설정 시 **화면 캡처**)이 증거로 전송됩니다.
- 비상 화면에서 **Cancel Emergency**(취소) 또는 **Lock Emergency**(잠금)를 선택할 수
  있습니다.
- SOS 버튼을 누르면 설정된 신호가 폰에서 실행됩니다.

## 4. 분실신호

- 보호자가 Telegram 봇에 **`/lost`** 를 보내면 분실 모드가 켜지고 **위치 공유**가
  시작됩니다.
- **`/stop`** 을 보내면 위치 공유가 중지됩니다.
- 분실 모드가 켜지면 기기에 "위치 공유 중" 화면이 투명하게 표시됩니다.

## 5. 패턴 감지 (톡톡·흔들기)

- 톡톡·흔들기 감지는 **기본 꺼짐**이며, 설정에서 직접 켤 때만 동작합니다.
- 평상시에는 마이크를 녹음하지 않습니다.

## 6. 데이터 보존·삭제

- 기기에 저장된 증거 파일(음성·경로·화면 캡처)은 생성 후 **7일 뒤 앱 시작 시 자동
  삭제**됩니다.
- 앱 데이터 삭제 또는 앱 제거로 로컬 데이터를 지울 수 있습니다.
- 삭제·문의: cloudseha@gmail.com · Telegram `@Memoriasafe_bot`

## 7. 주의

- 실행 중에는 Android의 마이크·위치 표시가 유지되며, 앱이 이를 끄거나 숨기지
  않습니다.
- Memoria는 응급구조기관을 대체하지 않습니다. 실제 위험 시 현지 긴급번호
  (한국 119·112, 미국 911 등)에 직접 신고하세요.
